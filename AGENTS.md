# AGENTS.md — инструкции за AI агента в това repo

Работиш по генерирането на нови студийни снимки за автопарка на Rent a Car Vratsa. 11 коли, 34 кадъра. Целта е да свършиш **колкото се може повече сам**, без да питаш за всяка стъпка.

## Автономен режим — това е основният път

Изпълни по ред, без да чакаш потвърждение между стъпките:

```
npm install                      # Playwright
npm run login                    # ЕДИНСТВЕНАТА стъпка, за която трябва човек
npm run proba                    # една кола за проба (peugeot-5008)
npm run generirai                # всички коли
npm run proveri                  # какво липсва
```

`npm run login` отваря Chrome и чака човекът да се логне в ChatGPT. **Ти не можеш да се логнеш вместо него** — не искай парола, не търси запазени пароли, не се опитвай да заобиколиш логин. Кажи му да се логне и да затвори прозореца, после продължи сам.

След това `avtomat.mjs` върши цялата работа: отваря нов чат за всяка кола, пише промпта, чака кадъра, сваля го в `koli/<кола>/novi/` с правилното име, продължава със следващия кадър, после със следващата кола.

Скриптът е **resumable** — прескача готовите файлове. Прекъсне ли се, просто го пусни пак.

## Какво правиш, когато нещо се счупи

1. **Прочети `avtomat.log`** — там пише точно кой кадър на коя кола е паднал и защо.
2. **Виж `_debug/`** — скриптът снима екрана при провал.
3. **Селекторите са в `avtomat.mjs`, обект `SEL` най-отгоре.** Ако ChatGPT е сменил интерфейса и композерът не се намира: отвори страницата, намери реалния селектор, обнови `SEL`, пусни пак. Това е основната поддръжка, която ще се наложи — прави я сам.
4. **Пусни пак само провалените** — `node avtomat.mjs --only <име-на-кола>`.
5. **Ако логът казва `BLOKIRANO`** — спри. Акаунтът иска верификация или е ударил лимит. Кажи на човека да я мине на ръка. **НЕ заобикаляй проверки, НЕ пробвай друг акаунт, НЕ сменяй user-agent, за да се скриеш.** Изчакай и продължи.

## Твърди забрани

- **Не правиш празни или фалшиви файлове**, за да „мине" проверката. Липсващият кадър е честен резултат; фалшивият файл е повреда, която ще стигне до клиентски сайт.
- **Не пипаш `PROMPT.txt`.** Промптите са одобрени и сверени по реалните снимки. Всяка редакция чупи единството между 11-те коли.
- **Не пипаш `sega/`** — това са референтните снимки.
- **Не преоразмеряваш, не конвертираш, не кропваш.** Става после, от друг.
- **Не качваш нищо на сайта.**
- **Не изтриваш файлове** без изрично „да".
- **Не заобикаляш анти-бот защити** и не се преструваш на друг браузър/устройство.

## Ръчен режим (когато автоматиката не тръгне)

Ако браузърната автоматизация се окаже неработеща, минаваш в помощник:

1. Прочети `PROGRES.md`, намери първата неотметната кола.
2. Изсипи съдържанието на нейния `PROMPT.txt` в чата, готово за копиране.
3. Човекът го пейства в **нов чат** в ChatGPT и сваля кадрите.
4. Ти проверяваш имената, преименуваш при нужда (**питай кой кадър кой е, ако не е ясно — не гадай**), пускаш `npm run proveri`, отмяташ в `PROGRES.md`, правиш commit.
