# Пускане — три команди

Работи през **твоя ChatGPT акаунт в истински Chrome**. Няма API, няма ключове, няма допълнително плащане.

## Какво трябва да има на машината

- **Node.js 18+** — провери с `node -v`. Ако липсва: https://nodejs.org (LTS)
- **Google Chrome** — обикновеният, инсталиран
- **ChatGPT акаунт** с генерация на изображения

## 1. Инсталирай

```
npm install
```

Тегли `playwright-core` — само библиотеката за управление на браузъра, няколко мегабайта. Браузър не се тегли: ползва се вече инсталираният Chrome.

## 2. Логни се веднъж

```
npm run login
```

Отваря празен Chrome прозорец на chatgpt.com. **Логваш се на ръка**, като видиш чата — просто затваряш прозореца.

Сесията се пази в папка `.chrome-profil/` вътре в проекта. Личният ти Chrome профил не се пипа — това е отделен, чист профил само за тази работа.

## 3. Пусни

Първо една кола за проба:

```
npm run proba
```

Ако кадрите излязат както трябва — пускаш всичко:

```
npm run generirai
```

Скриптът минава кола по кола: отваря нов чат, пише промпта, чака кадъра, сваля го в `koli/<кола>/novi/` с правилното име, пише в `avtomat.log` и продължава.

**Може да го спираш по всяко време.** Пуснеш ли го пак, прескача готовите файлове и продължава оттам, докъдето е стигнал.

## 4. Провери

```
npm run proveri
```

Показва кои коли са готови и кои кадри липсват.

## Когато нещо се счупи

**„образът не се появи"** — генерацията е била бавна или е гръмнала. Виж снимката в `_debug/`, после пусни пак — прескача готовото.

**„BLOKIRANO: страницата иска верификация или е ударен лимит"** — скриптът спира нарочно. Отвори браузъра на ръка, мини верификацията или изчакай лимита, пусни пак. **Не се опитвай да заобикаляш проверката** — това е знак да се намеси човек.

**Композерът не се намира / нищо не се пише** — ChatGPT е сменил интерфейса. Селекторите са събрани най-отгоре в `avtomat.mjs`, в обекта `SEL`. Кажи на Codex: „отвори chatgpt.com, намери полето за писане и обнови SEL в avtomat.mjs".

**Изходът е .png, не .jpg** — нормално е, така идват от ChatGPT. Не ги преименувай. Конвертирането става после.

---

## Важно да знаеш

Автоматизирането на ChatGPT през браузъра **противоречи на условията за ползване на OpenAI**. Акаунтът може да бъде ограничен. Затова скриптът работи бавно, с човешки паузи, и спира сам при засечена проверка вместо да я заобикаля.

Ако акаунтът започне да получава верификации — спри автоматиката и мини на ръка: всяка кола има `PROMPT.txt`, който се копира и пейства в ChatGPT. Пътят е същият, само по-бавен.

## Резервен вариант

В `_rezerva/generirai-API.mjs` стои скрипт, който прави същото през OpenAI Images API — по-стабилно и по правилата, но се плаща на кадър и иска API ключ. **Не се ползва по подразбиране.** Стои там само ако браузърният път се окаже неработещ.
