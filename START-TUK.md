# Нови снимки на автопарка — започни оттук

Здравей, Мартин. 11 коли, 34 нови снимки. **Почти всичко се прави само.**

Сегашните снимки на сайта са с налепен рекламен шум — стенен надпис, QR код, телефон, лента с иконки, цена върху снимката. Новите са чисти студийни кадри: само колата, тъмен фон, топла златна светлина, нула текст.

---

## Бързият път (препоръчан)

Отваряш терминал в тази папка и:

```
npm install          # еднократно
npm run login        # отваря Chrome → логваш се в ChatGPT → затваряш прозореца
npm run proba        # една кола за проба
npm run generirai    # всички 11 коли
npm run proveri      # какво липсва
```

Скриптът сам отваря нов чат за всяка кола, пише промпта, чака кадъра, сваля го на правилното място с правилното име и продължава. Може да го спираш — пуснеш ли го пак, продължава оттам, докъдето е стигнал.

Подробностите и какво да правиш при проблем: **`SETUP.md`**.

Ако работиш с Codex/AI агент — той чете `AGENTS.md` и знае всичко това. Кажи му просто: *„прочети AGENTS.md и почвай"*.

## Ръчният път (ако автоматиката спре)

Работи винаги, само е по-бавен:

1. Влизаш в папката на колата, отваряш `PROMPT.txt`.
2. **Нов чат** в ChatGPT → пействаш целия промпт.
3. Излизат 3 кадъра един след друг (при `03-peugeot-expert` — 4).
   Спре ли след първия: пиши `продължи с кадър 2`, после `продължи с кадър 3`.
4. Сваляш ги в `novi/` на същата кола: `01-front` · `02-rear` · `03-interior` · (`04-cabin` само за вана).
5. Отмяташ в `PROGRES.md`. Следваща кола — **нов чат**.

> **ЕДНА КОЛА = ЕДИН ЧАТ.** Смесиш ли коли в един чат, моделът почва да прелива цветовете — червеното става оранжево, каки-то кафяво. Автоматиката вече го спазва.

## Ако кадърът не стане

Не пиши промпта наново. Кажи в същия чат само корекцията:

- `по-силна златна светлина отзад, черното се слива`
- `махни отражението в капака`
- `завърти предните колела леко към камерата`
- `цветът стана кафяв, върни го към маслинено зелено`
- `колата опира ръба на кадъра, дръпни камерата назад`

---

## Кога кадърът е готов

- Нула букви и цифри в кадъра — включително по табелата и по екраните вътре
- Няма стенен надпис, QR код, телефон, лента с иконки, ценови етикет
- Цветът и джантите съвпадат със снимките в `sega/`
- Фонът е чисто тъмно студио — без мебели, растения, витрини, втора кола
- Черните и белите панели пазят детайл, не са слети петна
- Има въздух около колата (после се кропва до 16:10 — нищо важно да не опира ръба)
- Изглежда като снимка, не като 3D рендер

Като са готови всички — push или прати папката. Конвертирането (webp/avif), кропът и качването на сайта не са твоя работа.
